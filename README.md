## GitHub Pages 公開手順

1. GitHubで `yatta-everyday` という Public repository を作成
2. このフォルダ内のファイル・フォルダをすべて repository のルートへアップロード
3. GitHub repository の Settings → Pages
4. Build and deployment の Source を `Deploy from a branch`
5. Branch を `main`、Folder を `/ (root)` にして Save
6. 数分待って上記URLを確認
